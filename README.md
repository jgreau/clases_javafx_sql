# clases_javafx_sql

Material de DSY1102 (módulos 3.1 y 3.2): SQL, JDBC y JavaFX con arquitectura `controller → repository → dao`.

- `guias/Guia_1_Fundamentos_SQL.pdf`: SQL sin Java.
- `guias/Guia_2_SQL_en_Java.pdf`: instalación, JDBC y paso del DAO con JSON a un DAO con SQL.
- `guias/Guia_3_Ejercicios.pdf`: actividades y ejercicios con soluciones al final.
- `EjemploBiblioteca/`: proyecto JavaFX listo para ejecutar (`mvn javafx:run`). Ver su README.
